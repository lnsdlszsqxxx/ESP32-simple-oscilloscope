# ESP32-S3 Simple Oscilloscope

A simple ESP32-S3 oscilloscope that measures periodic low-voltage signals, captures five periods, and displays the waveform on a 128x64 SSD1306 OLED.

## Wiring

OLED:

```text
VCC -> 3.3V    GND -> GND
SDA -> GPIO8   SCL -> GPIO9
```

Self-test:

```text
GPIO1 (output) ---- jumper ---- GPIO4 (ADC input)
```

The OLED address is `0x3C`.

## Safety

Keep the GPIO4 input between `0V` and `3.3V`.

- Do not connect 5V or negative voltage directly.
- Connect the signal source ground to ESP32 GND.
- Use a voltage divider for signals above 3.3V.

## Build and Upload

```bash
pio run
pio run -t upload
pio device monitor
```

Serial speed: `115200` baud.

## Commands

| Command | Description |
|---|---|
| `?` | Show help |
| `q` | Reconfigure the square-wave output |
| `f200` | Set output frequency to 200Hz |
| `m` | Measure and display the waveform |

Self-test sequence:

```text
q
f200
m
```

## Measurement

The program finds the ADC minimum and maximum, uses their midpoint as the threshold, detects rising edges, calculates frequency, then samples five periods.

Current settings:

```cpp
static const int SAMPLE_COUNT = 100;
static const int SAMPLES_PER_PERIOD = 20;
```

The OLED shows frequency, ADC range, estimated voltage, and the waveform:

```text
F:200.0Hz
ADC:0-4095(3.30V)
```

Voltage estimate:

```text
voltage = ADC value * 3.3 / 4095
```

The test square wave is generated by the ESP32-S3 LEDC hardware peripheral with approximately 50% duty cycle. The project uses the Adafruit SSD1306 and Adafruit GFX libraries declared in `platformio.ini`.
# ESP32-S3 Simple Oscilloscope

A simple ESP32-S3 oscilloscope for measuring periodic low-voltage signals. It measures frequency through ADC rising-edge detection, captures five periods, prints the samples over Serial, and draws the waveform on a 128x64 SSD1306 OLED.

## Hardware

- ESP32-S3 N16R8
- 128x64 SSD1306 I2C OLED
- Jumper wire

### OLED wiring

The code uses GPIO8 for SDA and GPIO9 for SCL:

| OLED | ESP32-S3 |
|---|---|
| VCC | 3.3V |
| GND | GND |
| SDA | GPIO8 |
| SCL | GPIO9 |

The default OLED address is `0x3C`.

### Self-test wiring

```text
GPIO1 (square-wave output) ---- jumper ---- GPIO4 (ADC input)
```

GPIO1 generates the test square wave through the LEDC hardware peripheral. GPIO4 reads the input signal.

## Safety

Keep the GPIO4 input within:

```text
0 V <= GPIO4 <= 3.3 V
```

- Do not connect 5 V or negative voltage directly to GPIO4.
- Connect the external signal ground to ESP32 GND.
- Use a voltage divider for signals above 3.3 V.
- Use a DC bias circuit for bipolar signals such as `-1 V to +1 V`.

```bash
pio run
pio run -t upload
pio device monitor
```

The Serial Monitor uses `115200` baud. If the board is not detected at `/dev/ttyACM0`, update or remove `upload_port` and `monitor_port` in `platformio.ini`.

## Serial Commands

Enter a command and press Enter:

| Command | Description |
|---|---|
| `?` | Show help |
| `q` | Reconfigure the square-wave output |
| `f200` | Set output frequency to 200 Hz |
| `m` | Measure frequency, capture the waveform, and update the OLED |

Recommended self-test:

```text
q
f200
m
```

## Measurement Process

When `m` is entered, the program:

1. Finds the minimum and maximum ADC values.
2. Uses their midpoint as the threshold.
3. Detects low-to-high transitions.
4. Calculates frequency from the rising-edge timing.
5. Samples five periods.
6. Prints an ASCII waveform and draws the waveform on the OLED.

The current sampling settings are:

```cpp
static const int SAMPLE_COUNT = 100;
static const int SAMPLES_PER_PERIOD = 20;
```

The relationship should remain:

```text
SAMPLE_COUNT = SAMPLES_PER_PERIOD * 5
```

The OLED displays two information lines followed by the waveform:

```text
F:200.0Hz
ADC:0-4095(3.30V)
```

The displayed voltage is estimated with:

```text
voltage = ADC value * 3.3 / 4095
```

## Square-Wave Generation

The test signal is generated by the ESP32-S3 LEDC peripheral, not by a `while` loop and `delay()`:

```cpp
static const int LEDC_CHANNEL = 0;
static const int LEDC_BITS = 12;
```

A duty value of `2048` produces approximately a 50% duty cycle. After configuration, the hardware continues generating the wave while the CPU handles ADC sampling, OLED updates, and Serial commands.

## Limitations

- The input should be periodic and have sufficient amplitude.
- ADC sampling speed limits the useful input frequency range.
- OLED width is only 128 pixels, so many samples are compressed horizontally.
- The voltage display is an estimate, not a calibrated measurement.
- This project is intended for safe low-voltage signals, not mains voltage.
